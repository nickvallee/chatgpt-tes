# Reading App

A minimal web application for saving articles and reading them in a clean format.

## Setup

1. (Optional but recommended) Ensure you are using an up-to-date version of pip so it can download pre-built wheels:
   ```bash
   python -m pip install --upgrade pip
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python app.py
   ```
4. Open your browser at http://127.0.0.1:5000/.

From the index page, add article URLs to save them. The app downloads and stores a cleaned version of the article text for distraction-free reading.
